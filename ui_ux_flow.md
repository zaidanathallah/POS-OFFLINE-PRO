# UI/UX Flow & Wireframe Guidelines

## 1. Layar Pengaturan (Tambahan Backup & Restore)
- **Menu Database & Sinkronisasi:**
  - Card dengan icon Hard Drive/Database.
  - Tombol **"Backup Data (Export)"**: Menghasilkan file dan membuka modal "Save As" atau "Share" ke device.
  - Tombol **"Pulihkan Data (Import)"**: Membuka File Manager HP untuk memilih file backup yang ingin di-load.

## 2. Layar Laporan
- Tab Filter: Hari Ini, 7 Hari, 30 Hari, Kustom.
- Card Ringkasan: Omset, Transaksi, Rata-rata/Hari, Modal (HPP), Laba Kotor, Margin (%).
- Card Jam Sibuk & Hari Sibuk.

## 3. Layar Keamanan
- Toggle Aktifkan / Nonaktifkan PIN Pelindung Data.
